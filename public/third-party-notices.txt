Third-party notices — Cost of Living (au-inflation)

This site ships NO third-party runtime components. The entire application is
first-party TypeScript, hand-rolled SVG charts, and system fonts. There are no
bundled JavaScript libraries, no web fonts, and no external map/tile libraries.
(Verified from the build source maps: no node_modules sources are emitted into dist/.)

The build toolchain (Vite, TypeScript, Vitest, jsdom) runs only at build time and
is NOT distributed in the deployed site.
